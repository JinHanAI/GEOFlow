## 产品一句话

**GEOFlow** 是一个面向 GEO / SEO 内容运营场景的开源内容生产系统（Apache 2.0）：把「AI 模型配置 → 素材管理 → 任务调度 → 草稿审核 → 前台发布」串成一条完整链路，适合搭建自动化内容站点或内部内容运营后台；同时面向传统搜索引擎与 AI 引用（GEO）双优化。

## 分层技术清单

| 层 | 用什么 | 说明 |
|---|---|---|
| 后端与前台 | PHP 7.4+（单仓多入口：门户首页 / 文章页 / 分类 / 归档 / 路由器） | 内容站前台 + 运营后台一体；文章 SEO 元信息、Open Graph 与结构化数据齐备，另发布 llms.txt / llms-full.txt 供 AI 引用（GEO） |
| 数据库 | PostgreSQL | 稳定运行与并发写入；标题库 / 关键词库 / 图片库 / 知识库 / 提示词集中管理 |
| AI 层 | OpenAI 兼容接口的多模型接入 | 服务商可配置；批量任务创建、定时调度、队列执行与失败重试 |
| 工作流 | 草稿 → 审核 → 发布三段式 | 可切换自动发布；素材、任务、文章全后台管理 |
| 部署 & 工程化 | Docker Compose（本地 + 生产双编排）、启动脚本、健康入口 | 一条命令拉起；环境变量驱动（站点地址、时区、密钥、采集周期）；开源仓库含安全策略与声明文件 |
